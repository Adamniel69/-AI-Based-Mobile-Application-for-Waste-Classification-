# AI-Based Mobile Application for Waste Classification

An AI-based mobile application designed to help users identify waste items and find suitable recycling facilities through image classification and location-based recommendations.

## Documentation

- [Problem Statement](docs/problem%20statement.md)
- [Requirements](docs/requirements.md)
- [User Stories](docs/user%20stories.md)

## Project Status

**Current stage:** Planning and Requirements Documentation

The project is currently focused on defining the problem, identifying system requirements, and documenting user stories and acceptance criteria.

The next stages will involve system design, application development, AI model integration, testing, and evaluation.

## Main Objectives

- Develop an AI-based waste classification feature.
- Help users understand how to dispose of different waste items.
- Recommend suitable recycling facilities based on the identified waste.
- Provide a convenient and accessible mobile application for recycling guidance.

## Planned Features

- **AI Waste Classification:** Identify waste categories from images.
- **Recycling Guidance:** Provide disposal and recycling information for classified waste.
- **Recycling Facility Recommendations:** Help users locate suitable recycling facilities.
- **Location-Based Assistance:** Use location information to support facility recommendations.

*These features are planned and may be refined during development.*
